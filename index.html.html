يعمل دون إنترنت

☁️ المزامنة بين الأجهزة (Supabase)

يعمل محليًا — لم يتم تسجيل الدخول
الحفظ المحلي يعمل دون إنترنت. المزامنة تحتاج اتصالًا بالإنترنت وفتح الصفحة عبر HTTPS أو localhost. النظام يدعم مساحة عمل مشتركة حتى 5 حسابات عند تطبيق مخطط قاعدة البيانات وصلاحيات العضوية. احتفظ بنسخة احتياطية قبل أول مزامنة.
إعداد GitHub: يظهر المزوّد عندك بحالة Enabled، لكن يجب التأكد من إدخال Client ID وClient Secret الصحيحين داخل إعدادات GitHub في Supabase، ثم إضافة عنوان Callback الذي يعرضه Supabase في إعداد OAuth App على GitHub. افتح اللوحة عبر HTTPS أو localhost؛ فتحها مباشرة من Downloads (file://) لا يدعم تحويل OAuth بشكل موثوق.
يمكنك بدلًا من ذلك استخدام إرسال كود إلى البريد بعد ضبط إعدادات البريد في Supabase.
بعد تسجيل الدخول، اختر بوضوح اتجاه المزامنة. لن نستبدل البيانات تلقائيًا.
تنبيه: كلمة مرور حسابك تُرسل إلى خدمة Supabase للمصادقة فقط، ولا تُحفظ داخل نسخة البيانات. لا تستخدم أي مفتاح Service Role هنا.

قفل لوحة التحكم

كلمة المرور تُخزّن كمشتق تشفيري، لكن الملف المحلي لا يشفر كل بياناتك ولا يمنع شخصًا من تعديل HTML أو قراءة بيانات المتصفح. للحماية القوية استخدم جهازًا مشفرًا وقفل نظام التشغيل، ولا تحفظ معلومات شديدة الحساسية هنا.

مزامنة أوفلاين مشفّرة بين الأجهزة

بدون خادم أو إنترنت

لأنك تريد العمل أوفلاين بالكامل، لا توجد مزامنة تلقائية مباشرة بين الأجهزة. صدّر ملف مزامنة مشفّرًا بكلمة مرور مشتركة، وانقله يدويًا إلى الجهاز الآخر (USB أو Quick Share أو كابل)، ثم استورده هناك. الملف مشفّر بـ AES-GCM ومفتاح مشتق من كلمة المرور عبر PBKDF2. استخدم كلمة مرور مزامنة طويلة واحفظها؛ لا يمكن استعادة الملف المشفّر بدونها.

تنبيه: الاستيراد يستبدل بيانات اللوحة القابلة للمزامنة على هذا الجهاز. خذ نسخة احتياطية أولًا. كلمة مرور قفل الواجهة نفسها تبقى محلية لكل متصفح؛ يمكنك تعيين نفس الكلمة يدويًا على أجهزتك، لكن هذا ليس تحققًا مركزيًا.
